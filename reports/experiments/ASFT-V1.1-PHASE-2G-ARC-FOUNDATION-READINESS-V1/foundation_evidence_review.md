# Phase 2G.1 — Foundation Evidence Review

**Scope:** integration of Phases 2A–2F only. Phase 2G ran no ARC search, test scoring, or new representation comparison. Historical references are kept distinct from test-output-blind audits.

## Representation

- **Documented — PASS.** Phase 2A inventories the exact Phase 13G ten-program whole-grid DSL, auxiliary features/helpers, trace labels, and absent/partial concepts. No object-centric solution parser, explicit relation language, or general composition existed in the audited 13G solver.
- **Operational limits mapped — PASS.** `unsupported_v1` means no exact fit found in the bounded implementation; it does not prove semantic unrepresentability.
- **Alternative conditions — SPECIFIED, NOT IMPLEMENTED.** Phase 2F registered R0 historical, R1 current bounded reference, R2–R7 representation alternatives, and HCC. Alternative grammar/interpreters, adapter tests, HCC generator, and implementation hashes are pending.
- **Causal representation effect — UNRESOLVED.** No alternative has been compared under matched conditions. R0 historical is not a matched baseline because 13G discovery used 10 despite config 3.

## Coverage

- **Measurable — PASS for bounded found-fit coverage.** Phase 2B's coverage-only path and Phase 2C's paired S1–S4 runs are test-output blind. Phase 2B measured 2/1,000 fits at cap3 and 10/1,000 on the finite ten-program fullscan. Phase 2C measured 2, 5, 10, and 10 fits per 1,000 for S1–S4.
- **Separated from accuracy — PASS in Phase 2B/2C.** Accuracy was `NOT_MEASURED_BY_DESIGN`. This does not repair Phase 13G's historical combined path, in which coverage scanning called a solver that also evaluated task test outputs.
- **Ceiling — LIMITED.** This is fit coverage within a finite language, parameter inference implementation, candidate ordering, and budget—not the proportion of ARC tasks semantically representable.

## Search

- **New-run budget integrity — PASS in Phase 2C.** B1–B6 config/registry/runtime/log parity and deterministic cold-cache replay passed; candidate caps are separate from actual trials and first-fit skips.
- **Historical protocol — MISMATCH documented.** Phase 13G configured cap3, discovery used default cap10, scored arms used cap3, and the coverage scan used all ten. Search is ordered, first-fit, and does not retain all demo-consistent candidates. The mismatch remains historical evidence; it is not silently corrected.
- **Search/representation separation — PARTIAL.** Phase 2C identifies within-DSL budget effects. A representation-by-search causal contrast has not been run; parameter inference/ordering and the fixed candidate language still interact.

## Traces

- **Yield and validity measurable — PASS as an audit.** Phase 2D reconstructed 4,000 saved Phase 2C traces; all passed independent structural validation. Success counts were S1/S2/S3/S4 = 2/5/10/10 per 1,000.
- **Historical trace records — qualified.** 600 saved Phase 13G records passed retrospective structural validation, but the generation-time `trace_schema_valid` flag was hard-coded; no historical runtime validator is established.
- **Diversity/support — measurable, sparse.** Fullscan had ten successful traces across all splits but only three successful discovery traces per condition; exact solution-program/context support maxed at one. Generic trace-control n-grams recur, as separately measured in Phase 2E. Generality beyond demos was not measured.

## Invariants

- **Pipeline stages observable — PASS.** Phase 2E counted recurrence before thresholding and separately measured patterns, structures, candidate proposals, rejection reasons, and validation states.
- **Observed production path — BLOCKED upstream.** Only 1–3 successful discovery traces entered each miner run. Current frequency/cross-trace support 5 yielded zero raw patterns and zero production candidates.
- **Sensitivity result — diagnostic only.** Relaxed support 2 yielded recurring operation n-grams and two structures/proposals in the eligible sources, but these were generic search/verification fragments and both were rejected by `universal_noise`. Candidate quality/FDR and generality are not established; family labels were solver/program-derived.
- **Validation observability — PARTIAL.** Same-trace bypass diagnostics exercised validator stages, but no production candidate reached validation. No false-discovery rate or independent semantic validation is available.

## Representation comparison and downstream activation

Phase 2F specifies paired endpoints, common budgets, registries, HCC, activation states, and B1–B5 attribution. It does **not** implement or run R2–R7 or HCC. All 1,000 Phase 2C task IDs have already been inspected; comparisons on them are diagnostic only. A new authorized untouched common split, pre-run `δ_coverage`/activation margins, independent family annotations, and executable adapters remain required.

## Integrated evidence statement

Phase 2 has reliable test-blind diagnostics for bounded R1 coverage, search-budget effects, trace validity/yield, recurrence, and threshold attrition. It does **not** yet have an empirical alternative-representation contrast, a sufficiently recurrent semantic invariant corpus, independent invariant validation, or downstream skill/transfer/capability activation. Therefore it can localize observed failures within the tested R1 pipeline, but cannot yet reliably attribute ARC failures among representation, search, and downstream mechanism causes across alternatives.

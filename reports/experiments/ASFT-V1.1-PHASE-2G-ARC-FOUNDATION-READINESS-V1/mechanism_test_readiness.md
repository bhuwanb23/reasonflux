# Phase 2G.5 — ARC Mechanism Test Readiness

## Overall: **BLOCKED for confirmatory mechanism testing**

The pipeline is now more observable, but it has not supplied an adequate, independently validated mechanism substrate. Eligibility and lack of eligibility are reported separately; zero upstream inputs do not count as evidence that a downstream mechanism failed.

| Mechanism | Readiness | Current evidence | Gate before a meaningful test |
|---|---|---|---|
| **Invariant testing** | **PARTIAL diagnostics / BLOCKED efficacy test** | Recurrence and each mining stage are measurable. Current support5 yields zero patterns; relaxed support yields only generic trace-operation structures, with no accepted production candidates. | Adequate repeated successful traces; independently grounded semantic patterns/families; frozen support and candidate rules; positive-control miner plumbing; independent validation/truth procedure. |
| **Skill testing** | **BLOCKED** | No production invariant candidate or skill exists in 2B–2E; candidate→skill denominator is zero. | At least one accepted/validated invariant, pretested representation-to-skill adapter, same frozen SkillConfig/qualification, and eligible source evidence. |
| **Transfer testing** | **BLOCKED for ASFT skill transfer** | Phase 13G historical transfer probes and comparator outputs exist, but there was no supported invariant→skill pool; prior holdout is not pristine. | Eligible skill candidates, predeclared applicable-task denominator, fresh authorized transfer/replication split, and independent evaluation. |
| **Capability testing** | **BLOCKED** | No validated active skill/capability units reach the builder; capability eligibility has a zero upstream denominator. | Validated transferable skills under unchanged capability criteria, independent unit/coverage definition, and nonzero eligible inputs. |
| **Accuracy evaluation** | **NOT AUTHORIZED / NOT MEASURED in Phase 2A–2F diagnostics** | 2B/2C explicitly do not measure accuracy; 2F did not run. Phase 13G historical test-output scores are not pristine confirmation. | Separate authorization, sealed evaluator, untouched test set, public submission/score if leaderboard evidence is claimed. |

## Research questions

- **Q1 Can invariants exist?** Unknown. The current pipeline has not received a sufficiently recurrent, semantically grounded successful-trace corpus. No observed invariant is not proof of nonexistence.
- **Q2 Can skills form?** Not tested on ARC evidence; there are no eligible invariants.
- **Q3 Can transfer be measured?** Transfer metrics can be defined and historical probes audited, but ASFT skill transfer is blocked without eligible skills and a fresh independent split.
- **Q4 Can capability eligibility be measured?** The implementation criteria are inspectable, but eligibility is not empirically exercised on validated capability units; current state is `BLOCKED_UPSTREAM`, not zero capability/intelligence.

## Authorization rule

Do not unlock Phase 3/SCT or other confirmatory ARC mechanism evaluation based on Phase 2G. A separate readiness review must pass after alternative implementations, an adequate trace/invariant positive control, independent validation, a fresh split, and all protocol gates are complete.

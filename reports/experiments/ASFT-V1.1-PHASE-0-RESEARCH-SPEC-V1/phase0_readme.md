# ASFT v1.1 Phase 0

Primary artifact: [`phase0_v1_1_research_specification.md`](phase0_v1_1_research_specification.md).

Phase 0 is a research charter and readiness review—not an experiment phase. It classifies v1.0 claims and failures, preserves alternative explanations, defines RQ1–RQ7, freezes success and interpretation gates, and lays out the v1.1 master roadmap. Phase 0 passes readiness to begin Phase 1 design only; it does not authorize confirmatory data collection before benchmark, pressure, leakage, and preregistration gates are satisfied.

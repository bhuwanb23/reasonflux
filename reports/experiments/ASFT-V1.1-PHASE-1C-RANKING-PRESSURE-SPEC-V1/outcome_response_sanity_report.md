# Phase 1C — Outcome-Response Sanity Report

The runner computes rankings first, then constructs separate truth vectors solely to test the utility aggregator. A loss fixture assigns value to Frequency-only selections outside the IDT set; a tie fixture gives every candidate equal value; a win fixture assigns value to IDT-only selections. The metric reports all three relations correctly.

**This is a constructed metric-response contract, not an independent task outcome, not evidence that IDT wins or loses, and not a calibration/confirmatory result.** See `outcome_response_sanity.csv` for values.

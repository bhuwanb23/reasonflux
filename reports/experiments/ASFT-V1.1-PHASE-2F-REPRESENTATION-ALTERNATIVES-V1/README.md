## Key result

Historical evidence shows low coverage under the deployed ten-program representation, but also a clear search-budget effect within that same representation. Phases 2D–2E identify trace recurrence and support thresholds as separate downstream limits. Thus the representation hypothesis remains plausible and falsifiable, but **its causal contribution is unresolved**. All 1,000 Phase 2C task IDs have already been inspected; a rerun on them is diagnostic only, and confirmatory attribution requires a new authorized untouched common split. The primary proposed future contrast is R1 (current bounded reference) vs R3 (object-centric), with search, budgets, evaluator, and downstream mechanisms held fixed; HCC checks plumbing only and is not ARC evidence.

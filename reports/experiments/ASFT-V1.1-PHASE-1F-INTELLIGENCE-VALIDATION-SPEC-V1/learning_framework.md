# Phase 1F.6 — Future Learning Framework

## Learning target

The primary learning target is Test A's future learning curve on task families that are unseen after predictor time t. Systems receive a frozen number of examples at exposures 0, 1, 3, and 5; every score is taken on separate held-out items. The preregistered primary endpoint is normalized external AULC; slope, examples-to-criterion, one-/five-shot success, and delayed retention are secondary.

## Controls against prior competence and exposure

- Prior performance is measured on separate earlier tasks and included as B1.
- Experience count and prior task exposure are logged and included as B2.
- Existing capability, memory, and transfer are measured at t and included as comparators, not as future labels.
- Learning opportunities, feedback quality, demonstration count, test queries, memory access, and resource budgets are fixed/matched.
- Future items are distinct from demonstrations and absent from all memory/capability stores.

## Analysis

Estimate the family-level learning curve first, then average across families with equal weights. The primary predictive question is whether IG_t improves blocked held-out prediction of future AULC beyond the complete M0 simple-baseline model. The predictor may win, tie, lose, or be unavailable. A flat or negative curve is retained as observed; it is not repaired using IG or posthoc family removal.

Learning effects are behavioral. Without above-chance external acquisition on unseen items, a positive internal score cannot be called learning or intelligence growth.

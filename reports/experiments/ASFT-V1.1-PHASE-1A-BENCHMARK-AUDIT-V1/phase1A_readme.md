# ASFT v1.1 Phase 1A package

This folder contains the forensic benchmark audit of v1.0 Phases 13B–13G, with Phase 13A and Phase 11–12 implementation/readiness records included only as clearly labeled supplements. The audit reviews benchmark design and evidence; it does not rerun ASFT or collect confirmatory data.

## Start here

- [`phase1A_review.md`](phase1A_review.md) — findings, scope limits, exit decision, and file index.
- [`phase1A_readiness_checklist.csv`](phase1A_readiness_checklist.csv) — exit criteria and status.
- [`benchmark_redesign_requirements.csv`](benchmark_redesign_requirements.csv) — traceable v1.1 requirements for follow-on designs.

# Competition and Paper Submission Checklist

This checklist complements research validation. Recheck current official Kaggle rules; the rules and runtime contract are authoritative.

## ARC-AGI-2

- [ ] Competition joined; team/participant and final submission match paper team.
- [ ] Notebook runs with internet disabled if required; all models/assets are permitted, available offline, and license/provenance documented.
- [ ] Correct input file, all required task IDs, exact output schema, permitted number of attempts/outputs.
- [ ] Uses official evaluator or starter to validate formatting on a non-hidden sample.
- [ ] Runtime, accelerator/memory, timeout and file-write constraints tested in Kaggle-like environment.
- [ ] Save Kaggle notebook URL/version, submission ID, run logs, model resource versions, and score.
- [ ] Paper describes the code actually submitted, not unimplemented roadmap items.

## ARC-AGI-3

- [ ] Competition joined; team/participant and final submission match paper team.
- [ ] Agent API, observation/action schema, reset/episode boundaries and score verified against current official kit.
- [ ] Offline/model constraints, resource limits, time budget, allowed actions, and licenses checked.
- [ ] Smoke test on official sample environment; record errors, throughput, action validity, and score.
- [ ] Save Kaggle notebook URL/version, submission ID, run logs, model/resource versions, and score.
- [ ] Paper describes the submitted agent and its tested memory/skill behavior exactly.

## Paper Track

- [ ] Select the prediction submission the paper documents; paper-team association is correct.
- [ ] Writeup is within 1,500 words; includes abstract/intro, prior work, algorithm-level method, actual results, and conclusion.
- [ ] Distinguishes leaderboard score from controlled experiments and reports only verified numbers.
- [ ] Includes real public notebook and required cover image/media gallery; project link requirements satisfied.
- [ ] All third-party methods/assets/models credited and licenses checked; results reproducible from instructions.
- [ ] Saved writeup is explicitly **submitted**, not left as a draft; save final submission receipt/time.

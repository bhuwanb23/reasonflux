# P1 — Prior-art matrix

**Status:** design/documentation work package only. Completion does not authorize code, experiments, benchmarks, ARC runs, split assignment, or access to restricted outcomes.

## Objective

Establish whether counterexample-guided invariant applicability boundaries are distinct from trace distillation, skill refinement, options, replay and predictive gates.

## Inputs and dependencies

Dependencies follow the T2T master plan; existing project restrictions remain controlling.

3. **P1.3 — Novelty decision:** Select retain, narrow, reframe, or stop based on exact overlap.

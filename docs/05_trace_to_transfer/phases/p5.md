# P5 — Experimental protocol design

**Status:** design/documentation work package only. Completion does not authorize code, experiments, benchmarks, ARC runs, split assignment, or access to restricted outcomes.

## Objective

Design a future study with claim-specific estimands, fair arms, permitted data, resources and falsification.

## Inputs and dependencies

Protocol design draft; all thresholds/sample size remain unset.
Dependencies follow the T2T master plan; existing project restrictions remain controlling.

## Work sequence

1. **P5.1 — Arms and estimands:** Select claim-specific treatment/control arms and primary/secondary estimands.
2. **P5.2 — Data and budgets:** Define permitted source experience, target cohort, separation, resources, resets and environment constraints.
3. **P5.3 — Metrics:** Specify official score, prediction quality, coverage, negative transfer, costs and failure denominators.
4. **P5.4 — Analysis and falsifiers:** Define uncertainty, multiplicity, exclusions, minimum meaningful effect and stop rules.

## Deliverable

Complete protocol proposal that could be reviewed separately for authorization.

## Acceptance and boundary

Review the deliverable for internal consistency, version it, and record unresolved questions. **Boundary:** Not a preregistration or approval; no split assignment, hidden/test access, or run.

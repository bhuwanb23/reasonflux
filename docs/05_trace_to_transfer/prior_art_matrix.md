## Provisional synthesis

The proposed novelty center is now directly crowded: SkillApt studies state-conditioned activation-boundary learning from paired outcomes; BASM uses explicit boundary-aware skill records; SelSkill trains local invoke/skip policies; issue #6645 publicly proposes counterexample-qualified refinement of reusable skill guards; and ARC-AGI-3 systems repair models from predictive mismatches. The components are not identical, but the current title/contribution cannot support a first-method claim.

The remaining candidate is a **comparative research question**, not cleared novelty:

> In interactive ARC-like environments, does cross-context structural action/effect representation add held-out value beyond outcome-based activation, boundary-aware skill records, guard-refinement analogues, per-environment model repair and strong parameterized/compressed replay at matched resources?

Current disposition: **no-go on the standalone method novelty claim; owner selected the comparative ARC-specific reframe for idea-stage work on 2026-11-03**. This is not a novelty assertion or execution authorization. SAGE primary sources remain inaccessible, and no bounded review can prove global absence. See [`novelty_decision.md`](p1/novelty_decision.md).

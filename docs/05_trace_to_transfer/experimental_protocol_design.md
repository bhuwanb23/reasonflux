# Future Experimental Protocol Design — Entry Point

**Controlling protocol proposal:** [`T2T-P5-Protocol-v1.0.0-draft`](p5/protocol_v1.md)  
**Status:** complete for design/documentation scope only; not preregistration, implementation, run authorization, split assignment, or restricted-outcome access.

The versioned P5 proposal covers claim-specific arms/estimands, permitted source and target-data roles, resource matching, resets/environment constraints, metrics/denominators, uncertainty/multiplicity, exclusions, falsifiers, and stop rules. It is reconciled to the [P3 fair-replay controls](p3/fair_replay_controls_v1.md), [P4 boundary algorithm](p4/boundary_algorithm_v1.md), and current [claim-evidence ceiling](current_evidence.md).

Numerical effect thresholds, alpha/confidence level, sample size/power, exact manifests/cohort, task IDs/splits, metric operating points, budgets, and named owners/reviewers remain `UNSET`. Those are freeze-gate fields for a separately reviewed and authorized protocol. This page grants no code, data, or execution approval.

## Validity note: N is blocked for decision-grade interpretation

The S1.2 metric/direction were set before the run, but the **R1-Max implementation was not fully frozen before the first outcome**. The first pilot used a positive-trace shared-slot macro that abstained outside its template and produced an apparent N-PASS (I0 8/8, replay 4/8). After seeing that result, the replay baseline was strengthened to fit the shortest source-consistent conjunction in a fixed predicate grammar; I0 was also revised to fit-check on the same source corpus. The same N holdout was reused.

That is outcome-informed baseline/model revision on an exposed holdout. Accordingly:

- v0 is an exploratory pilot, **not** evidence for N;
- v1's raw tie is useful as a replay expressivity sensitivity check, but it is **not an independent confirmation**; and
- the correct decision-grade N status for this S2 sequence is **N-BLOCKED**, not N-PASS or a clean N-FAIL.

The v0 stdout is preserved; its overwritten full JSON is not reconstructed or fabricated. The revised run was re-executed after input-validation hardening and produced the same raw scores; this added no new contexts and is not an independent replicate.

## Revised-run raw measurements

The revised run followed the strengthened bounded trace-to-script baseline and used the same eight N contexts. Its raw measurements were:

| Test | Arm/version | Correct / denominator or rate | Interpretation |

| **N: exact effect prediction** | I0 invariant predictor | 8/8 = 1.00; coverage 8/8 |  |

|  | I0 − R1-Max | 0.00 accuracy difference | N status remains **BLOCKED** because the baseline/model changed after v0 and the holdout was reused |
| **B: false activation** | I0, frozen G0 | 2/4 non-applicable contexts; 2/2 applicable contexts admitted; 4/6 total admitted |  |
|  | I1, CE-updated G1 | 0/4 non-applicable contexts; 2/2 applicable contexts admitted; 2/6 total admitted | **B-PASS on this fixed fixture** |

The revised replay compiler found the shortest conjunction consistent with the synthetic source traces in its frozen grammar: `adjacent AND door_closed AND has_key AND corridor_clear AND key_color == door_color`. It therefore reproduced I0's predictions on the eight contexts. This illustrates that a compact script can represent the same simple rule; it does not establish that all forms of replay will match every invariant.

For B, the B-specific positive supports, red-key/blue-door counterexample, G0/G1 update, criterion, and six holdout contexts remained the same in the pilot revision (the shared source corpus was expanded to fit the stronger R1/I0 models). The counterexample was admitted by G0, had a frozen skill-effect prediction of success, and produced no successful effect. I1 appended a successor guard adding `key_color == door_color`. On six fresh contexts, false activations fell from 2 to 0 while applicable-context coverage stayed at 2/2. Total activation fell from 4/6 to 2/6 and is reported.

## Interpretation

- **N:** no valid decision yet. The revised raw score is a tie; the initial apparent advantage came from a less capable replay implementation. A fresh, prospectively frozen N test is required before classifying Claim N.
- **B:** the fixed CE update improved boundary classification in this hand-designed deterministic fixture without losing positive coverage. This is not evidence of reduced task harm, population generalization, cost-effectiveness, or novelty.
- Therefore S1.1 outcome O3 (N fails, B succeeds) is **not assigned**; N is blocked, not established as failed. P1's no-go on generic counterexample-guided guard refinement remains controlling.

## Validity limits

This is a small, deterministic, hand-designed finite world with a known rule and tiny predeclared predicate vocabulary. It does not test open-ended invariant discovery. The I0 candidate family and replay grammar are narrow; the boundary update uses one explicitly selected predicate. There are no uncertainty intervals or population estimates. B's labels and holdout are generated by the same known world function. No cost or task-level harm endpoint was measured.

No ARC/AGI-3, Mini-ARC, competition task, evaluator, network, model, leaderboard, restricted outcome, or real-world environment was accessed. No full skill system, lifecycle manager, SCT, CGM, transfer metric, or paper artifact was implemented.

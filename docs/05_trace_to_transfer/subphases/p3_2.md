# P3.2 — Strong replay

**Parent:** [T2T-P3](../phases/p3.md)  
**Status:** COMPLETE for documentation/design scope; not a readiness gate or authorization.

## Deliverable

R1 specification and competence-review requirements in the [P3 fair replay contract](../p3/fair_replay_controls_v1.md#3-arm-definitions).

## Control definition

R1 is a competent compact/parameterized procedure built from the same permitted source traces. It may deduplicate and compress exact sequences, use typed action/effect slots with declared schema/field/position binding rules (including new literal IDs), retrieve among trace-derived scripts with the common retrieval interface, branch only among source-derived procedures, transport aligned recorded effects for prediction, and use ordinary execution checks and safe stop/fallback behavior. It must get the same source evidence, model/tool opportunity, input/context, wrapper, retrieval budget, construction opportunity, and action/compute caps as the treatment.

The controlling contract supplies a minimum source-only construction recipe: exact subsequence compression, fixed operation/field/type alignment, typed slots only when they reconstruct source instances, recorded expected effects carried through those same slots, shared retrieval, and abstention on unresolved bindings. It must not learn or store an explicit cross-context state/action/effect invariant, a generalized applicability boundary learned from counterexamples, an outcome-conditioned activation rule, or a novel effect relation from target outcomes. Fixed schema/type/field/position rules may bind new literal IDs in target contexts; outside those rules or when binding is ambiguous, it abstains. This avoids a straw baseline while preserving the representation distinction. If R1 behavior functionally matches the invariant treatment, count that as a result against a demonstrated invariant-specific increment; do not relabel the baseline after outcomes.

Before any separately authorized evaluation, freeze/hash R1 and obtain a documented independent competence review of its capabilities, constraints, resource parity, and non-use of invariant boundary learning. P3 defines this review but has not built or reviewed a baseline.

## Unresolved for a future authorized protocol

Concrete compression/retrieval/binding algorithm, reviewer qualifications, data manifest, model, observation schema, cap values, cost accounting and evaluation cohort remain unset. No outcome-based baseline tuning or target-outcome exposure is allowed. No baseline implementation or experiment was performed.

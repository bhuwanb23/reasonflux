# P6.1 — Architecture

**Parent:** [T2T-P6](../phases/p6.md)  
**Status:** COMPLETE for documentation/design scope, 2026-11-04. No implementation or authorization.

## Deliverable

[`T2T-P6-Blueprint-v1.0.0-draft — Architecture`](../p6/architecture_v1.md), covering modules, trust boundaries, data flow, runtime and baseline interfaces, lifecycle gates, non-goals, and budget accounting. The original [`implementation_blueprint.md`](../implementation_blueprint.md) is now an entrypoint to the versioned documents.

## Result

Specified logical control, source-ingress, formation/versioning, runtime, event-journal, restricted-evaluation and analysis zones. CandidateVersion cannot flow directly to execution; only a separately specified and authorized SkillVersion can reach the runtime gate. Baselines and treatments share a wrapper contract. Prediction, action, transition/effect assessment, evaluator outcome and cost records remain separate; no restricted-outcome feedback path is designed into construction/refinement.

Defined conceptual interfaces for proposal/review/specification, decision, applicability, prediction, action/fallback, effect assessment, cost and evaluator interaction. Resource accounting follows P3/P5's vector; numerical caps and parity acceptance values remain unset.

## Unresolved and boundary

Language, deployment topology, event store, artifact registry, schema migration process, identity/hash profile, access-control/security implementation, environment/evaluator adapter, cost units/caps, and named reviewers remain open. This is a design artifact only; no code or tool was built or run.

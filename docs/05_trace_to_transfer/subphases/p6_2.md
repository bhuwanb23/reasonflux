# P6.2 — Event schema

**Parent:** [T2T-P6](../phases/p6.md)  
**Status:** documentation/research-design only; not a readiness gate or authorization.

## Purpose

Specify immutable events for observations, actions, predictions, transitions, candidate versions and costs.

## Required work

- State definitions and assumptions explicitly; cite source documents and versions.
- Document alternatives considered, unresolved decisions, and how each would affect the central claim.
- Keep source data, evidence provenance, and claim interpretation auditable.
- Ask for owner review before treating any consequential ambiguity as resolved.

## Guardrails

Capture allowed provenance only; protect credentials and distinguish unknown from absent.

## Deliverable and review test

Versioned schema and example event chain.

The reviewer should be able to determine what was decided, what remains unknown, and what evidence would falsify or revise the design without executing an experiment. Any numerical threshold, split, or eligibility rule not already approved must remain unset.

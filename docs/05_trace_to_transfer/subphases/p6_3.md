# P6.3 — Contract tests

**Parent:** [T2T-P6](../phases/p6.md)  
**Status:** COMPLETE for documentation/design scope, 2026-11-04. The P6 test plan was not executed at phase completion; a separate authorized Step 1 later ran a focused synthetic-only subset for the local event journal. The full P6 test plan remains unimplemented.

## Deliverable

[`T2T-ContractTests-v1.0.0-draft`](../p6/contract_test_plan_v1.md), a synthetic test matrix for strict parsing/P2-P4 interoperability, immutability and determinism, pre-action ordering, applicability/abstention, fallback/fail-closed behavior, baseline/replay interfaces, budget parity, accounting and trust-boundary isolation.

## Result

Each test defines synthetic inputs and expected contract behavior. It includes negative cases for unknown fields/versions, invalid lifecycle transitions, after-action predictions, unknown caps, uncharged retries, outcome leakage and candidate execution. Resource parity requires prospectively approved cap refs; with caps unset, only the block-on-missing behavior can be specified. No tests have been executed, and passing future contract tests would not be scientific evidence or run approval.

## Unresolved and boundary

Test framework, parser/dialect, property/fuzz approach, mock environment, clock/concurrency injection, security test harness, coverage criteria and named engineering/security reviewers remain open. Implementation and testing require separate authorization; no restricted data or evaluator access is enabled.

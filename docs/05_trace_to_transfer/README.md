# From Trace to Transfer — Research Plan

This folder contains the idea-stage research plan for **Counterexample-Guided Invariant Skills for ARC-AGI-3**. Start with:

1. [`core_idea.md`](core_idea.md) — research question, thesis, scope, and novelty ceiling.
2. [`current_evidence.md`](current_evidence.md) — current ReasonFlux evidence and claim limits.
3. [`master_plan.md`](master_plan.md) — dependency-ordered work packages and subphases.
4. [`prior_art_matrix.md`](prior_art_matrix.md) — first-pass comparison matrix. The linked [`P1 review packet`](p1/README.md) contains the source inventory, mechanism comparison, and interim novelty disposition.
5. [`formal_skill_object.md`](formal_skill_object.md) — proposed object contract.
6. [`claim_n_specification.md`](claim_n_specification.md) — invariant representation versus strong replay controls.
7. [`counterexample_boundary_algorithm.md`](counterexample_boundary_algorithm.md) — proposed candidate/scope/refinement logic.
8. [`experimental_protocol_design.md`](experimental_protocol_design.md) — future protocol design only, not authorization.
9. [`implementation_blueprint.md`](implementation_blueprint.md) and [`evaluation_reporting_plan.md`](evaluation_reporting_plan.md) — architecture and reporting plan.
10. [`formal_terms_and_decisions.md`](formal_terms_and_decisions.md) — working definitions and unresolved choices.

Each T2T phase and subphase has its own file under [`phases/`](phases/) and [`subphases/`](subphases/). The eight phase briefs are [`P0`](phases/p0.md), [`P1`](phases/p1.md), [`P2`](phases/p2.md), [`P3`](phases/p3.md), [`P4`](phases/p4.md), [`P5`](phases/p5.md), [`P6`](phases/p6.md), and [`P7`](phases/p7.md). Each phase brief links to its separate subphase documents. Codes are prefixed `T2T-` to distinguish this plan from the repository’s earlier Phase 2/3 work.

## Important status

These are **research-design work packages**, not new readiness phases. They do not authorize Phase 2I, Phase 3B, Phase 3D, confirmatory runs, hidden/test-outcome access, or Kaggle submission. Phase 3A remains plumbing only. No AGI-3 runs or results are recorded in the workspace. Any future execution requires the applicable existing authorization and data-integrity gates.

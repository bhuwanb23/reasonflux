# From Trace to Transfer — Research Plan

This folder contains the idea-stage research plan for **Counterexample-Guided Invariant Skills for ARC-AGI-3**. Start with:

1. [`core_idea.md`](core_idea.md) — research question, thesis, scope, and novelty ceiling.
2. [`current_evidence.md`](current_evidence.md) — current ReasonFlux evidence and claim limits.
3. [`master_plan.md`](master_plan.md) — dependency-ordered work packages and subphases.
4. [`prior_art_matrix.md`](prior_art_matrix.md) — compact prior-art comparison. The linked [`completed P1 packet`](p1/README.md) contains the source inventory, mechanism comparison, owner-selected reframe, and novelty-clearance limits.
5. [`formal_skill_object.md`](formal_skill_object.md) — P2 formal object contract; see the [P2 schema and fixtures](p2/README.md).
6. [`claim_n_specification.md`](claim_n_specification.md) — versioned Claim N; see the [P3 fair replay packet](p3/README.md) for controls, budgets, estimands, ablations and falsifiers.
7. [`counterexample_boundary_algorithm.md`](counterexample_boundary_algorithm.md) — P4 entry point; see the [versioned P4 algorithm and fixtures](p4/README.md).
8. [`experimental_protocol_design.md`](experimental_protocol_design.md) — entry point to the [versioned P5 protocol proposal](p5/README.md); not authorization.
9. [`implementation_blueprint.md`](implementation_blueprint.md) and [`evaluation_reporting_plan.md`](evaluation_reporting_plan.md) — entrypoints to the [versioned P6 build plan](p6/README.md) and [P7 reporting packet](p7/README.md).
10. [`formal_terms_and_decisions.md`](formal_terms_and_decisions.md) — working definitions and unresolved choices.
11. [`s1/README.md`](s1/README.md) — mechanism-feasibility decisions for Claims N and B, followed by the separately authorized [S2 synthetic prototype and results](s2/README.md).
12. [`s3/README.md`](s3/README.md) — implementation-authorized, no-run Claim N package, with independent competence review and separate run gates.

Each T2T phase and subphase has its own file under [`phases/`](phases/) and [`subphases/`](subphases/). The eight phase briefs are [`P0`](phases/p0.md), [`P1`](phases/p1.md), [`P2`](phases/p2.md), [`P3`](phases/p3.md), [`P4`](phases/p4.md), [`P5`](phases/p5.md), [`P6`](phases/p6.md), and [`P7`](phases/p7.md). Each phase brief links to its separate subphase documents. Codes are prefixed `T2T-` to distinguish this plan from the repository’s earlier Phase 2/3 work.

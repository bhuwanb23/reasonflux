Research Thesis

After all investigations, the central ASFT thesis is:

Intelligence emerges when repeated reasoning experiences are transformed into reusable skills that reduce future reasoning cost.

Everything else derives from this.

Master Research Question (MRQ)

This should become the paper's central question.

Can an agent improve future problem-solving capability by converting repeated reasoning patterns into reusable skills?

This is the overarching research question.

Contribution 1
Invariant Discovery Theory (IDT)
Problem

Current systems typically learn:

Solutions
Programs
Rules


But not necessarily:

What remains invariant across experiences

Core Claim (C1)

Transferable knowledge is best represented as invariants discovered across reasoning experiences.

Hypothesis H1

Reasoning traces that share a common latent structure will produce stable invariants.

Strong Hypothesis H1A

Higher invariant strength leads to higher transfer potential.

Mathematically:

Invariant Strength ↑
→
Transfer Score ↑

Prediction P1

If multiple reflection tasks are observed:

Reflect Shape A
Reflect Shape B
Reflect Shape C


ASFT should discover:

Reflection


as an invariant.

Prediction P2

Discovered invariants should appear across task families rather than single tasks.

Evidence Required

Need to show:

Invariant Detected
↓
Reused Later
↓
Transfer Improved

Falsification Condition

IDT is weakened if:

Detected invariants
≠
Useful transfer structures


or

Random patterns perform equally well

Contribution 2
Skill Creation Trigger Theory (SCT)

This is likely our strongest contribution.

Problem

Most systems answer:

How to use a skill?


Few answer:

When should a skill be created?

Core Claim (C2)

A new skill should emerge when future reasoning savings exceed skill creation cost.

Hypothesis H2

Skill creation decisions based on reasoning economics outperform fixed skill creation strategies.

Strong Hypothesis H2A

When:

Expected Future Savings
>
Creation Cost


creating a skill yields positive long-term utility.

Prediction P3

ASFT should create fewer but more useful skills than naive skill creation.

Prediction P4

Automatically created skills should be reused across future tasks.

Prediction P5

Reasoning cost should decrease after skill formation.

Evidence Required

Need:

Skill Created
↓
Skill Reused
↓
Reasoning Cost Reduced

Falsification Condition

SCT fails if:

Created skills
rarely reused


or

Skill creation
does not reduce cost

Contribution 3
Capability Growth Metrics (CGM)
Problem

Current systems are evaluated primarily through:

Accuracy


But ARC's philosophy is closer to measuring skill acquisition and generalization efficiency. On the Measure of Intelligence defines intelligence around skill-acquisition efficiency rather than task-specific performance.

Core Claim (C3)

Intelligence growth should be measured by improvement on future tasks, not only success on current tasks.

Hypothesis H3

Systems exhibiting positive transfer should display measurable capability growth.

Strong Hypothesis H3A

Capability Growth Rate (CGR) predicts future performance better than task accuracy alone.

Prediction P6

Agents with higher transfer scores will show higher CGR.

Prediction P7

Capability metrics will continue increasing even when task accuracy plateaus.

Evidence Required

Need:

Task Sequence
↓
Capability Increase
↓
Future Performance Increase

Falsification Condition

CGM is weakened if:

CGR
does not correlate
with future capability

System-Level Hypothesis

Now let's combine all three contributions.

Grand Hypothesis (GH)

This should become the centerpiece of the paper.

Agents that discover invariants, create skills selectively, and accumulate reusable capabilities will achieve higher transfer efficiency than agents that only optimize task solutions.
